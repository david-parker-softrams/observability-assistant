================================================================================
INVESTIGATION SUMMARY
================================================================================

PROBLEM:
  Users cannot select or copy text from the chat window.
  This blocks critical workflows like copying error messages and logs.
  Impact: Blocks all users from a core feature.

ROOT CAUSE:
  Mouse event interception by VerticalScroll container prevents the Static
  widget's text selection from working.

SOLUTION:
  Replace Static widgets with TextArea (read_only=True) to enable native
  text selection that's not affected by container event interception.

KEY FINDINGS:
  ✓ Textual 7.5.0 available
  ✓ Static widget has allow_select=True but can't receive focus
  ✓ TextArea has full selection support with read_only mode
  ✓ Problem is mouse event interception, not widget capability
  ✓ TextArea is the standard solution for read-only text with selection
  ✓ Implementation is straightforward (~40 lines of code)
  ✓ No new dependencies required
  ✓ Zero breaking changes
  ✓ Backwards compatible

================================================================================

================================================================================

APPROACH 3: TextArea with read_only=True

✅ Why This Approach:
  • Solves 100% of the problem

  • Better performance than custom solution
